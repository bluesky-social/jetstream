# Imported `indexed_at` Durability: Rule Map Stamped at Ingest

**Superseded (2026-09-25): removed.** The timestamp import pipeline described here was deleted ahead of disaggregated storage (`specs/notes/2026-09-25-disaggregated-storage-v2-design.md` §21, implementation-plan task S0.1). The `indexed_at` column remains and is always `0`. This note is kept as history; re-adding import under a new design is tracked in [issue #354](https://github.com/bluesky-social/jetstream/issues/354).

**Status: decided design, not yet implemented; tracking [issue #269](https://github.com/bluesky-social/jetstream/issues/269).** The decision was to persist imported-indexed-at rules and stamp matching events during live/backfill ingest, while import updated the rule map and existing segments; compaction and resync would preserve the stamped value. The note accepted bounded lookup/cache and rule-lifecycle limitations rather than re-running imports on every new event.
