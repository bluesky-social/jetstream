# Issue #200 — Segment-File I/O Fault Injection Layer Handoff

This historical implementation handoff identified three remaining gaps after #201/PR #239: `segment.Patch` and `segment.Rewrite` lacked I/O seams, injectors were not plumbed into a running server, and compaction/import did not consistently classify ENOSPC as fail-loud. The approved work added package seams, runtime wiring, a full oracle segment-fault tier, and two mutation tests, explicitly including ENOSPC parity. References were `segment/iofault.go`, `segment/writer.go`, `internal/ingest/enospc.go`, `internal/jetstreamd/runtime.go`, `internal/oracle/`, and `testing/mutation/run.sh`.
