# [Issue #200](https://github.com/bluesky-social/jetstream/issues/200) — Segment-File I/O Fault Injection Layer Handoff

This historical implementation handoff identified three remaining gaps after [issue #201](https://github.com/bluesky-social/jetstream/issues/201)/[PR #239](https://github.com/bluesky-social/jetstream/pull/239): `segment.Patch` and `segment.Rewrite` lacked I/O seams, injectors were not plumbed into a running server, and compaction/import did not consistently classify ENOSPC as fail-loud. The approved work added package seams, runtime wiring, a full oracle segment-fault tier, and two mutation tests, explicitly including ENOSPC parity. References were child issues [#256](https://github.com/bluesky-social/jetstream/issues/256), [#257](https://github.com/bluesky-social/jetstream/issues/257), and [#258](https://github.com/bluesky-social/jetstream/issues/258), implementing [PR #263](https://github.com/bluesky-social/jetstream/pull/263), parent epic [#35](https://github.com/bluesky-social/jetstream/issues/35), `segment/iofault.go`, `segment/writer.go`, `internal/ingest/enospc.go`, `internal/jetstreamd/runtime.go`, `internal/oracle/`, and `testing/mutation/run.sh`.
