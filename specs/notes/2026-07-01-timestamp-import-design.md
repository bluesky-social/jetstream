# Timestamp Import + Witnessed/Indexed Timestamp Rename

**Superseded (2026-09-25): removed.** The timestamp import pipeline described here was deleted ahead of disaggregated storage (`specs/notes/2026-09-25-disaggregated-storage-v2-design.md` §21, implementation-plan task S0.1). The `indexed_at` column remains and is always `0`. This note is kept as history; re-adding import under a new design is tracked in [issue #354](https://github.com/bluesky-social/jetstream/issues/354).

**Status: implementation complete.** The design retained two timestamp columns, renamed their semantics to witnessed and imported indexed time, and resolved wire `time_us` as imported-when-present otherwise witnessed; sentinel zero represented no import without changing the on-disk format. It implemented a bearer-gated online CSV job using a disk-backed, crash-safe `segment.Patch`/compaction-pass pipeline keyed by AT URI, with bounded row rejection and no dry-run or provenance field. References were [issue #193](https://github.com/bluesky-social/jetstream/issues/193), implementing [PR #196](https://github.com/bluesky-social/jetstream/pull/196), landing dependency [PR #195](https://github.com/bluesky-social/jetstream/pull/195), `docs/README.md`, `segment/patch.go`, `internal/timestamp/`, `internal/importer/`, and `cmd/jetstream/main.go`.
