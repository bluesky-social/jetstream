# `planSnapshot`: Wildcard Collection Filters

**Status: approved design, pre-implementation.** The decision was to keep the existing collection field and interpret validated trailing-wildcard values as prefix matches inside `internal/manifest/plan.go`, rather than expanding collections at request time. The plan required strict validation, cap semantics, lexicon updates, equivalence/property tests, integration tests, and fuzzing. References were `internal/manifest/plan.go`, `internal/xrpcapi/plansnapshot.go`, and `internal/subscribe/filter.go`. GitHub: [issue #73](https://github.com/bluesky-social/jetstream/issues/73), [PR #74](https://github.com/bluesky-social/jetstream/pull/74).
